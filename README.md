# Banking Fraud Analysis Dashboard

## Overview

The Banking Fraud Analysis Dashboard is a Power BI project developed to analyze banking transactions and identify fraudulent activities. The dashboard provides a comprehensive view of transaction performance, fraud trends, customer risk factors, and channel-level insights to support data-driven decision-making.

This project demonstrates my skills in Power BI, SQL, Excel, Data Modeling, DAX, and Business Intelligence as a Data Analyst Fresher.

---

## Project Objective

The objective of this project is to analyze banking transactions and uncover fraud patterns by answering key business questions:

- What percentage of transactions are fraudulent?
- Which transaction types have the highest fraud occurrence?
- How does fraud vary across channels and regions?
- What factors influence fraud rates?
- How can banks improve fraud monitoring and prevention?

---

### 2. Fraud Analysis Dashboard

Analyzes fraud patterns across:

- Transaction Types
- Banking Channels
- Regions
- Monthly Fraud Trends

Key Findings:

- Withdrawal transactions recorded the highest fraud cases.
- Transfer and Deposit transactions showed significant fraud activity.
- Fraud cases remained relatively consistent throughout the year.
- Fraud occurs across all banking channels including UPI, ATM, POS, Internet Banking, Branch Banking, and Mobile Banking.

---

### 3. Customer Risk Dashboard

Focuses on identifying factors influencing fraud.

Key Influencers Analysis revealed:

- Fraud Percentage increases when Fraud Transactions increase.
- Login Attempts have a significant relationship with fraud behavior.
- Failed Transactions contribute to fraud risk patterns.

Additional Analysis:

- Login Attempts by Channel
- Fraud Percentage Drivers
- Customer Risk Segmentation

---

## Business Insights

- Withdrawal transactions are the most fraud-prone transaction type.
- Fraud is distributed across all banking channels, requiring multi-channel monitoring.
- Higher fraud transaction volumes directly impact fraud percentages.
- Login behavior can be used as an early fraud risk indicator.
- Monthly fraud trends help identify seasonal transaction risks.

---

## Business Recommendations

### Fraud Prevention

- Implement real-time fraud monitoring systems.
- Introduce risk-based authentication for suspicious transactions.
- Strengthen monitoring for withdrawal and transfer transactions.

### Customer Security

- Trigger alerts for abnormal login activity.
- Monitor customers with repeated failed transactions.
- Apply additional verification for high-risk users.

### Operational Improvements

- Perform periodic fraud audits across all channels.
- Use predictive analytics to identify fraud patterns earlier.
- Develop fraud risk scoring models for customers.
